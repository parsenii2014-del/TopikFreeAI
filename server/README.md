# FreeAI Cloud 0.6

Один сервер без зависимостей (Node 18+), чтобы всё работало без включённого ноутбука и телефона.

| Что | Как |
|---|---|
| Прокси к FreeLLMAPI | `/v1/*`, приложению нужен только токен сервера |
| Серверный «мозг» | запрос с полем `freeai` в `/v1/chat/completions`: инструменты, проверка ответа рецензентом, совет моделей, агенты |
| Цены подарков | `/gifts/floor?collection=plushpepe`, `/gifts/top`: Fragment, Portals, MRKT |
| Алерты 24/7 | `/alerts`: крипта (CoinGecko) и флоры подарков, уведомления в Telegram |
| Синхронизация | `/sync`: история чатов и память между устройствами |
| Фото и видео | `POST /v1/images`, `POST /v1/videos` → `GET /v1/videos/<id>` → `GET /media/<id>.mp4` (Pollinations или OpenAI-совместимый API) |
| Дизайн и планировка | режимы `design` и `plan` серверного мозга: ответ с готовым SVG/HTML |
| Автономные задачи | `/tasks`: расписание, только чтение и уведомления в Telegram, суточный лимит и аварийная пауза |
| Диагностика площадок | `GET /gifts/diagnose`, `GET /gifts/raw?source=portals|mrkt` |
| Telegram-бот | чат с ИИ, `/code`, `/agent`, `/deep`, `/search`, `/price`, `/gift`, `/top`, `/watch`, `/watches`, `/memory`, `/image`, `/video`, `/design`, `/plan`, `/task`, `/tasks`, `/stopall`, `/diag` |

## Запуск (Docker на VPS)

```bash
cd server
cp .env.example .env     # впиши TOKEN, UPSTREAM_URL, при желании бота и ключи площадок
docker compose up -d --build
node test.js             # самопроверка с моками (нужен Node 18+)
```

Нужен **HTTPS** (Caddy или Cloudflare Tunnel): токены передаются в заголовках и теле запросов.

## Приложение

Настройки: «API URL» `https://сервер/v1`, «API-ключ» = `TOKEN`; «Облако» `https://сервер` (без `/v1`).
Переключатели «Серверный мозг», «Глубокий режим», «Совет моделей» включают серверные пайплайны.

## Источники цен на подарки

- **Fragment**: бесплатно, ключ не нужен. Открытый ежедневный датасет Baltic Assets (CC BY 4.0): цены раз в сутки, это цены продавцов, а иногда аукционов.
- **Portals**: официальный Partner API (`/partners/collections/preview`, заголовок `Authorization: partners <ключ>`). Ключ создаётся в мини-приложении Portals. Лимит бесплатного тарифа примерно 1 запрос в секунду. Если сервер получает 403 от Cloudflare, нужно разрешение поддержки Portals.
- **MRKT**: официального API нет. Используется `POST https://api.tgmrkt.io/api/v1/gifts/saling` с токеном твоей сессии. Токен протухает, формат ответа может измениться; единицы цены определяются эвристически.

Цены Portals и MRKT разобраны по описанию библиотек и документации, живых ключей у меня не было. Если площадка поменяет формат, источник вернёт понятную ошибку, остальные продолжат работать.
Единица цены везде GRAM (так с 15 июня 2026 называется бывший TON). Комиссии площадок не учитываются.

## Безопасность

- Бот отвечает только id из `TG_OWNER_IDS`, чужим сообщает их id и больше ничего.
- `fetch_url` блокирует локальные и внутренние адреса (защита от SSRF), проверяет и перенаправления.
- Токен бота из приложения хранится в `data/alerts.json` (права 600) и наружу не отдаётся. Заведи отдельного бота для уведомлений.
- Подбор моделей и проверки улучшают ответы, но потолок качества задают модели в твоём FreeLLMAPI.

## Как заставить Portals и MRKT работать

Свои аккаунты и коды из Telegram никому не передавай, достаточно ключей, которые ты получишь сам.

1. **Portals.** В мини-приложении Portals открой профиль → Partner API и создай ключ. Впиши его в `PORTALS_API_KEY`.
2. **MRKT.** Выполни у себя `python tools/mrkt_token.py --api-id ... --api-hash ... --out server/data/mrkt.token` (понадобится `pip install pyrogram tgcrypto requests` и api_id/api_hash с my.telegram.org). Скрипт запросит код из Telegram локально, а токен запишет в файл. Сервер читает файл сам (`MRKT_TOKEN_FILE`), повторяй скрипт по cron раз в 12 часов.
3. **Проверка.** Отправь боту `/diag` или открой `/gifts/diagnose`: там видно, какие поля вернула каждая площадка. Если цена не разобралась, пришли мне вывод `/gifts/raw?source=mrkt` (там только данные рынка, секретов нет), и я подстрою разбор.

Автоматизация сессии Telegram может нарушать правила площадок и Telegram, поэтому для неё лучше завести отдельный аккаунт.

## Автономность и ограничения

- Задачи только читают (поиск, курсы, цены) и пишут тебе. Покупок, платежей и действий от твоего имени инструментов нет.
- Лимиты: минимум `TASK_MIN_MINUTES` между запусками, `AUTONOMY_MAX_RUNS_DAY` запусков в сутки, `/stopall` останавливает всё сразу.
- Фото и видео проходят через модерацию провайдера. Правила моделей и провайдеров я не отключаю.
